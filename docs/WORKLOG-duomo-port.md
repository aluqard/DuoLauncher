## 1. 목표와 원칙

### 목표
Duomo 런처(`com.bgiseok.crease`)의 기능을 Duo Launcher에 옮기고, 이후 사용자 요청에 따라 UI·동작을 다듬는다.
Duomo는 Duo Launcher를 바탕으로 만든 런처로, 데이터 모델(스키마 8, `leadingSlots`)을 그대로 쓰면서 일반 폰 지원, 꾸미기, 세워 두기 모드 등을 더한 것으로 분석되었다(분석 보고서: `F:\Work\rea\2026-11-26_DuomoLauncher\report.md`).

### 원칙 (클린룸 재구현)
- Duomo의 코드, 이미지, 번역, 글꼴은 가져오지 않았다. 디컴파일 코드와 Duomo 자체 그림(아이콘, 모래 언덕/밤하늘 배경, 시계 모양)은 사용하지 않았다.
- 참고한 것은 동작 사양뿐이다: 분석 보고서, 에뮬레이터에서 Duomo를 직접 실행해 찍은 화면과 측정값.
- Duomo의 밤하늘 배경은 이미지를 복사하지 않고, 같은 분위기의 장면을 코드로 직접 그렸다.
- 글라스 도어 셰이더는 참고한 저장소의 셰이더 출처에 라이선스가 없어(7.12절) 직접 새로 작성했다.

## 4. 1단계: Duomo 기능 이식 (`c927a9f`)

계획(`작업 계획 파일(로컬)`)의 0~4단계를 구현했다.

### 4.1 기반
- 레이아웃 스키마 9: 숨긴 앱, 앱/카테고리 재정의(이름·아이콘), 독 위치, 메인 페이지, 기본 위젯 내용(메모·체크리스트)을 추가했다. 이전 스키마는 `state_v8_backup`으로 보존한다.
- 백업 형식 v3(v1·v2도 읽음).
- `ThemeStore`(아이콘 스타일·팩·모양·색) 도입.
- `LauncherScreen.kt`의 일부를 `Dock.kt`, `HomeChrome.kt`, `BuiltinWidgets.kt` 등으로 분리했다.
- `DeviceStatus`에 충전 방식(무선/AC/USB)과 다음 알람을 추가했다.

### 4.2 시계와 작은 기능
- 아날로그 시계 위젯: 화면에 보일 때만 프레임 단위로 초침이 부드럽게 움직인다.
- 알림 배지: 개수만 세고 알림 내용은 읽지 않는다.
- 앱 숨기기와 생체 인증 잠금.
- 앱 메뉴: 아이콘·이름 바꾸기, 숨기기, 제거.
- 고정 요청(위젯·바로가기) 수락.
- 자동 백업(변경 시·매일·매주, 7개 또는 30개 보관).

### 4.3 테마와 꾸미기
- 아이콘 파이프라인을 `Icons.kt`로 정리했다.
- iPhone 스타일 아이콘: 연속 곡률 모서리, 흰 판, 밝게/어둡게/색조 모드. 각 앱 자신의 아이콘에 적용하며 Apple 아이콘은 쓰지 않는다.
- 외부 아이콘 팩(ADW/Nova 등의 `appfilter.xml`).
- 색 테마, 룩 프리셋(배경+테마+레이아웃 저장, 요일·시간 예약 전환).
- 기본 위젯: 메모, 체크리스트, 배터리, 다음 알람.

### 4.4 일반 폰 지원
- 독 위치: 아래/왼쪽/오른쪽(폰 기본은 아래, 폴더블 펼침은 오른쪽).
- 카테고리별 All apps(추천, 최근 추가, 카테고리 폴더).
- 편집 모드: 상단 도구 막대(위젯·설정·프리셋·크기·완료), 여러 개 선택 후 폴더 만들기·페이지 이동·제거.
- 페이지 편집기: 순서 바꾸기, 추가, 삭제, 메인 페이지 지정.

### 4.5 세워 두기 모드(Stand mode)
- 자세 판별: 책 / 노트북 / 커버 화면 옆으로 / 펼쳐 세움. 힌지 각도, 중력, 충전, 조도를 쓴다.
- 시계·달력·알람·배터리 화면, 어두우면 붉은 야간 모드.

### 4.6 그 밖의 UI (같은 커밋)
- 돋보기 버튼: 탭하면 All apps 화면으로 넘어가지 않고 홈이 흐려지며 앱 검색 화면이 아래에서 올라온다. 취소하면 반대로 사라진다. 길게 누르면 Google 검색.
- 페이지 점(젤리 효과), 설정 미리보기, 배경·모양 설정 화면.
- 유리 그림자: 기본 그림자가 반투명 유리 아래로 비쳐 아이콘 사이와 돋보기 버튼 안이 얼룩져 보였다. 그래서 모양 바깥에만 그림자를 그리는 `outerShadow`로 바꿨다.

## 5. 2단계: 독과 유리 효과 (`4fd7ccc`, `a282622`)

### 5.1 오른쪽 독을 Duomo처럼 (`4fd7ccc`)
- **크기**:
  - Duomo의 독 막대는 실제로 약 95dp이다(설정 값은 68dp).
  - 그래서 저장된 독 너비를 아이콘 열로 보고, 막대는 27dp 더 넓게 그린다.
  - 독 아이콘은 홈 아이콘과 같은 크기이며, 네 칸이 홈 앱 행과 줄을 맞춘다.
- **간유리 효과**:
  - 펼친 화면에서 페이지가 움직이는 동안에는 독 아래까지 지나가고, 독 안에서는 흐리게 비친다.
  - 멈춰 있을 때 독 아래에는 아무것도 그려지지 않고 눌리지도 않는다.
  - 페이지가 독 가장자리에서 끊기지 않도록, 보이는 영역이 부드러운 경계로 넓어진다.
- **구현 메모**:
  - Duomo는 미리 흐리게 만든 배경 사진을 독 아래에 깐다.
  - 이 런처는 홈 페이지 레이어를 다른 곳에서 다시 그리면 아무것도 나오지 않았다(오프스크린 합성 레이어의 한계).
  - 그래서 페이지 레이어 자체에 "독 모양 부분만 흐리게" 하는 렌더 효과를 걸고, 흐린 배경 조각은 페이지 아래에 깔았다.
- **Discover 연동**: Discover 화면의 독과 창 분할 비율도 새 너비를 쓴다.

### 5.2 모든 독에 적용 (`a282622`)
- **커버 화면**: 오른쪽 독 아래로도 페이지가 지나가며 흐리게 비친다.
- **일반 폰 하단 독**:
  - Duomo처럼 All apps 내용이 독 뒤까지 이어지고, 독 안에서 흐리게 보인다.
  - 목록 끝에는 여백이 있어 마지막 항목도 독 위로 스크롤할 수 있다.
- **하단 독 크기**:
  - 먼저 Duomo 규칙(첫 열 아이콘 왼쪽 끝부터 마지막 열 오른쪽 끝까지)으로 맞췄다.
  - 이후 사용자 요청으로, 네 아이콘을 감싸고 사방에 14dp만 남기도록 줄였다.
- **검색**: 일반 폰에서는 독 위 가운데에 "Search" 알약 버튼을 둔다. 탭하면 앱 검색, 길게 누르면 Google. All apps 화면, 드래그 중, 편집 모드에서는 숨긴다.
- **유리 입체감**:
  - 채움: 위가 밝고 아래가 약간 어둡다.
  - 테두리: 왼쪽 위·오른쪽 아래 모서리가 밝고 옆면은 옅다.
  - 적용 대상: 독, 검색 버튼, All apps 검색창·카테고리 타일, 위젯, 폴더.
  - 이후 "너무 밝다"는 의견으로 색을 60%로 낮추고(`GLASS_CLARITY`) 블러를 10dp로 줄였다. 열린 폴더 패널은 글자 가독성 때문에 그대로 두었다.
- **배경**: 직접 그린 "Starry night"(별, 지평선의 노을빛, 어두운 모래 언덕)가 기본이다. 설정에서 "Duo dunes"를 고를 수 있고, 시스템 라이브 배경도 같은 선택을 따른다.
- **Discover**: "Swipe right for Discover" 스위치를 추가했다(기본 꺼짐). 꺼져 있으면 오른쪽 스와이프, 첫 페이지 끌어당김, 페이지 점의 Discover 동작, Discover 페이지가 모두 사라진다. 계측 테스트는 `DuoTestRunner`가 스위치를 켠 상태로 실행한다.
- **위젯 배치**:
  - 실제 칸 위치로 계산한 외곽선이 격자에 정확히 맞는다. 전에는 상태 표시줄만큼 어긋나 있었다.
  - 미리보기를 손가락으로 끌 수 있고, 외곽선이 칸 단위로 따라온다.
  - 이미 찬 칸 위에서는 위젯과 외곽선이 빨갛게 바뀌고, 놓으면 마지막으로 들어갈 수 있었던 자리로 돌아간다.
  - 새 페이지에 배치할 때 All apps가 보이던 문제도 고쳤다.
- **드래그 중 스크롤**: 위젯을 끌 때 홈이 자동으로 스크롤되지 않는다. 앱 아이콘 드래그는 그대로 스크롤된다.

## 6. 3단계: 글라스 도어(Glass Door) (`d7d5821`, `1daacdc`)

### 6.1 검토
- `marcoazeem/duo-open`(MIT)을 분석했다.
- 이 앱은 접근성 서비스와 화면 캡처로 모든 화면 위에 효과를 그린다.
- 런처는 홈을 직접 그리므로 접근성 서비스 없이 실시간 화면에 효과를 줄 수 있다고 판단했다. 대신 홈에서만 동작한다.
- 핵심 셰이더의 원본(`Atomicx7/Duo-animation`)에는 라이선스 파일이 없다(직접 확인). 그래서 셰이더를 직접 새로 작성했다.

### 6.2 동작 (`GlassDoor.kt`)
- **내부 화면**: 접거나 펼칠 때 움직이는 반쪽(기본 왼쪽)이 힌지에 매달린 간유리처럼 보인다.
  - 힌지에서 멀수록 더 흐리고 어둡다.
  - 바깥 가장자리가 살짝 뒤로 물러난다.
  - 평평하게 펼치면 선명해진다.
- **커버 화면**: 거의 닫힐 때 화면이 커버로 넘어가면 효과가 이어진다.
  - 접힌 쪽(왼쪽 가장자리)이 선명하고 오른쪽으로 갈수록 흐리다.
  - 닫히면서 맑아진다. 펼칠 때는 반대 순서다.
- **각도 → 흐림**:
  - 내부 화면: 172°에서 0, 110° 이하에서 최대. 평평한 상태를 벗어나자마자 빠르게 오른다(160°에서 약 35%).
  - 커버 화면: 8° 이하에서 0, 화면이 넘어가는 각도에서 최대.
- **화면 전환 각도 학습**: 한쪽 화면의 마지막 측정값과 다른 쪽의 첫 측정값으로 계산해 저장한다. 학습 전에는 30°를 쓰며, 에뮬레이터에서는 23°를 학습했다.
- **0/90/180°만 보고하는 힌지**(Galaxy Z Fold 등):
  - Android 공개 접힘 상태가 "평평"에서 "반쯤 열림"으로 바뀌는 순간을 접기 시작으로 본다.
  - 측정값이 없는 구간에서도 흐림을 3초 유지한다(일반 힌지는 0.9초).
  - 닫혀서 커버가 켜지면, 첫 측정값이 0°여도 완전히 흐린 상태에서 시작해 0.65초 동안 맑아진다.
- **멈춤**: 중간에 멈추면 잠시 뒤 흐림이 사라지고, 다시 움직이면 돌아온다.
- **센서 사용**: 힌지 센서는 홈이 화면에 있고 효과가 켜져 있을 때만 읽는다.
- **기기별 렌더링**: Android 13 이상은 직접 작성한 AGSL 셰이더, Android 12는 화면 전체를 고르게 흐리게 하는 대체 효과를 쓴다.

### 6.3 설정
- 메인 설정 화면(Stand mode 아래, 힌지 센서가 있는 폰만): "Glass door when unfolding" 켜기/끄기.
- 배경 및 모양 → Folding: "Frost strength"(50–150%), "Frosted half"(Left / Both / Right, 기본 Left).

### 6.4 세워 두기 모드 변경 (같은 시기)
- 120° 정도로 들고 있으면 세워 두기 모드로 바뀌던 문제가 있었다. 기본값이 "Always"여서 1.5초 반쯤 접힌 상태가 유지되면 열렸기 때문이다.
- 기본값을 **Only while charging**으로 바꿨다. 이미 고른 값은 그대로 둔다.
- 메인 설정 화면에 "Stand mode turns on: Off / Always / Only while charging" 선택을 추가했다.

## 9. 알려진 한계와 미확인 사항

- **글라스 도어 동작 범위**: 홈에서만 동작하며 다른 앱 위에는 나타나지 않는다(접근성 서비스는 의도적으로 쓰지 않음).
- **화면 전환 순간**: 대부분의 폴더블은 내부 화면과 커버 화면이 동시에 켜지지 않아, 전환 순간에 잠깐 검게 보인다(시스템 동작).
- **0/90/180° 힌지에서의 대응**: 손의 움직임을 정확히 따르지 못하고 시간 기반으로 근사한다.
- **커버 화면 페이지 범위**: 왼쪽 독(일반 폰 옵션)은 페이지가 독 아래로 지나가지 않는다.
- **일반 폰 하단 행**: 그리드가 독 위 공간보다 약간 커서 아래 행이 가려질 수 있다. 위젯 드래그 자동 스크롤을 끈 결과, 위젯은 그 행에 끌어 놓을 수 없다.
- **하단 독 너비**: Duomo와 정확히 같은 dp는 아니다. 같은 규칙을 우리 그리드에 적용한 값이다.
- **에뮬레이터 기본 홈 앱**:
  - 진행 중에 폴더블 에뮬레이터의 기본 홈 앱이 한때 해제되었다. 이후 콜드 부팅에서 Duo Launcher로 돌아왔다.
  - 폰 에뮬레이터는 재시작 후 기본 홈이 Duomo로 되어 있었다.
  - 사용자 요청에 따라 기본 홈 앱은 직접 바꾸지 않았다.
- **에뮬레이터 상태**: 두 에뮬레이터 모두 현재 꺼져 있다.
